这一版改了什么：从「放大的仪表盘」到「一整块仪表台」

上一版我把「大气」理解成尺度——把数字放大到 120px、把环放大到 400px。那只是把仪表盘放大，本质没变：元素一样多、一样挤，只有「大而全」，没有「从容」。

这一版的核心动作只有一句话：拆掉所有卡片。卡片网格是网页的语言，一整块被发丝线切分的连续画布才是仪器的语言。卡片一拆，留白立刻有了张力，元素数量也自然减半。

科技感的五个来源（都不是光效）

来源具体做法为什么有效
等宽数字所有数值用等宽字体 + tabular-nums，界面文案全中文、不出现英文标签数字跳动时不位移；等宽数字是「仪器/终端」的视觉母语，成本最低、效果最强。科技感不依赖英文——中文字距收紧后同样成立
发丝线1px / 0.055 透明度的线取代全部卡片边框，区域靠线切分而非框包围细线需要精度才画得准，「精度」就是科技感的心理基础
刻度与角标顶/底边缘刻度尺（20px 细刻度、100px 粗刻度），四角 54px 直角角标刻度尺是测量仪器的独有元素；出血到边缘才有指挥屏感，留一圈 padding 就还是网页
数据即纹理每个指标下方 38px 频谱条、底栏 56px 吞吐频谱（含峰值虚线、基线、时间轴）——全是真实数据，不是装饰远看是材质，近看是数据。装饰要花钱维护，数据纹理零成本且永远在变
动效即信息轨道扫描扇 11s 一圈、连线上的数据包流动、告警节点脉冲 + 涟漪动的是「状态」不是「装饰」；三条循环动效是节奏，超过三条就开始干扰阅读

大气的四个体验来源

  • 从容——元素从 7 个区块减到 5 个，留白面积增加约 40%。画面不急于填满，才显得这个系统游刃有余。
  • 掌控——中央轨道拓扑是唯一主角，左右两列在字号和线的强度上明确降级为它的注释。三栏平权等于没有主角。
  • 精准——所有发丝线、刻度、角标对齐同一套 60px 栅格；数字全部等宽右对齐。对齐本身会传递「可靠」。
  • 克制——整屏只有一种主色（青），只有异常才允许彩色。13 个节点里 11 个是中性色，只有 2 个有问题的是琥珀/红。
中央轨道拓扑在表达什么：三条同心轨道 = 三个区域（核心区 / 应用区 / 边缘区），节点在轨道上的位置 = 部署位置，节点大小 = 规格权重，连线上的流动数据包 = 实时流量。它不是装饰盘，是 13 台主机的真实拓扑——这也替代了原来的地图模块（13 台主机的地理分布信息量极低，却要占四成面积，还有地图合规成本）。

底部那条频谱是什么

它是实时入向吞吐——每根柱子是一个采样点的网络入向流量，整条随时间向左滚动，覆盖最近 5 分钟。上方标了均值、峰值、出向、包速率与会话数，橙色虚线是峰值参考线，下方有「5 分钟前 / 2 分钟前 / 现在」的时间轴。

它同时承担两个作用：一是给底栏一条真实、永远在变的数据纹理（比任何装饰都耐看，且零维护成本）；二是让「流量是否异常」在余光里就能感知——当大量柱子顶破峰值线时，不用读数字也知道出问题了。

第一版它只是一排随机柱子、没有任何标注，所以需要解释才看得懂。需要解释的设计就是没传达出去的设计，这一版已补齐标题、单位、时间轴与峰值线。真实实现接采集接口的时间序列即可，不需要新增字段。

全中文界面

界面文案统一中文：标题、指标名、状态语、告警等级、时间轴全部中文化；节点代号用「库1 / 应3 / 网1」这类两字缩写，可读性优于英文缩写。仅保留两类例外：数值单位（%、Gb/s、ms）与真实主机名（db-prod-01）——这两类在中文运维界面里替换成中文反而更难读。

字距同步调整：中文在 0.2em 以上的字距会散架，全部收到 0.08–0.14em；等宽字体栈末尾补了中文字体，避免中文回退到不匹配的默认字体。

告警态：整屏换温，不是局部换色

切到告警态后变化的不是某一个组件：顶部 3px 红边、四角角标变红、刻度尺变红、背景光晕转红、中央环内数字变琥珀、严重告警节点红色脉冲 + 涟漪扩散、底栏遥测流转蓝。三米外一眼能看出出事了——这是大屏真正的价值时刻。

同时右侧队列第一条直接给研判结论（「约 6 小时后写满，建议清理归档表或扩容 200GB」），容量预测图上也标出了触顶点。让人不用自己从 3 条告警里找答案。

仍然不做的三件事：粒子连线背景（7×24 投屏常驻逐帧重绘，显卡开销换不来任何信息量，且是 2018 年的标志性元素）、渐变发光标题字（它会让全屏信息量最低的东西最抢眼）、旋转地球 / 3D 城市（信息量低 + 地图合规）。
但补回了材质的「物理感」：噪点 4.5% + 扫描线 1.7% + 三层径向光晕 + 四周暗角。这四层极淡，单独看几乎不可见，合在一起让屏幕从「平面色块」变成「有厚度的发光体」。上一版我为了去俗套把它们一起删了，那是错的——去掉装饰不等于获得气质，结果是干净但冰冷。

双档：演示档 / 值班档

顶部可切换。演示档开扫描、数据流、脉冲、噪点扫描线（展厅、参观、截图）；值班档关掉全部循环动效与背景材质层，但构图与字号完全不变。持续运动的元素盯两小时会让人眼疲劳。默认值建议演示档——大屏在这个项目里更多承担展示职能，值班同学真正盯的是主站。
